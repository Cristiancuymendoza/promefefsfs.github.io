# Promo 5B — versión para GitHub Pages

Esta carpeta está preparada para publicarse como sitio estático en GitHub Pages.

## Cómo publicarla
1. Descarga y descomprime el ZIP.
2. En tu repositorio de GitHub, sube **el contenido de esta carpeta** (no la carpeta contenedora). `index.html`, `styles.css`, `app.js` y `.nojekyll` deben quedar en la raíz del repositorio.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, pulsa **Save**.
6. Espera unos minutos y abre la dirección que aparece en la sección Pages.

## Importante
GitHub Pages solo publica HTML, CSS y JavaScript. El diseño y las animaciones funcionan, pero el formulario no guarda mensajes y el panel de administración/subida de fotos y videos no funcionará aquí sin conectar un servicio externo. Para tener mensajes compartidos, inicio de sesión y subida de archivos hace falta alojar el backend en otro servicio.
